1 · Create a payment & redirect (cURL)

curl -X POST {{ base_url }}/api/v1/payments \
  -H "Authorization: Bearer <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
        "amount": "30.00",
        "currency": "DJF",
        "reference": "ORDER-123",
        "title": "Wallet top-up",
        "customer_ref": "user-42",
        "return_url": "https://your-site.com/thank-you"
      }'

# → { "payment_id": "pay_...", "status": "PENDING", "checkout_url": "https://..." }
# Redirect the customer to checkout_url.

2 · PHP (Laravel / Guzzle)

$res = Http::withToken(env('DMONEY_PLATFORM_KEY'))
    ->post('{{ base_url }}/api/v1/payments', [
        'amount'    => '30.00',
        'currency'  => 'DJF',
        'reference' => $order->id,
        'title'     => 'Wallet top-up',
        'return_url'=> route('payment.return'),
    ]);

return redirect()->away($res['checkout_url']);   // send the customer to pay

3 · JavaScript (Node / fetch)

const r = await fetch("{{ base_url }}/api/v1/payments", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.DMONEY_PLATFORM_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    amount: "30.00", currency: "DJF",
    reference: order.id, title: "Wallet top-up",
    return_url: "https://your-site.com/thank-you",
  }),
});
const { checkout_url } = await r.json();
res.redirect(checkout_url);                        // send the customer to pay

4 · Poll a payment's status

curl {{ base_url }}/api/v1/payments/pay_xxx \
  -H "Authorization: Bearer <YOUR_API_KEY>"
# → { "status": "SUCCESS", "trade_no": "DM...", "paid_at": "..." }

Tip: you don't need to poll if you set a result webhook — we POST the final status to your webhook_url automatically.
